Runtime & Inference Configuration

                Changes apply immediately and persist to config
              

              

                

                  

                    
                    
                    
HTTP endpoint of the PS5LM inference server. Default: http://127.0.0.1:8081/v1. Local loopback avoids LAN latency; remote URLs add network round-trip overhead.

                  


                  

                    
                    
                    
Default model identifier used when an agent has no model override. Default: qwen-loaded. Auto-updated when PS5LM capability sync is enabled.

                  


                  

                    
                    
                    
Wire protocol for PS5LM inference calls. Default: chat_completions. Use chat_completions or responses for tool calling, vision, and streaming.

                  


                  

                    
                    
                    
Default reasoning depth for thinking-capable models. Default: medium. Higher levels improve complex coding/planning accuracy at the cost of extra tokens and latency.

                  


                  

                    
                    
                    
Automatically aligns loaded model, context window, and slot concurrency from PS5LM. Default: true. Prevents OOM/context mismatches with minimal background overhead.

                  


                  

                    
                    
                    
Seconds between background PS5LM capability probes. Default: 30; 0 = manual sync only. Very low values increase periodic localhost HTTP traffic.

                  


                  

                    
                    
                    
Stream tokens and thinking deltas live via SSE as PS5LM generates them. Default: true. Disabling increases perceived latency with negligible RAM savings.

                  


                  

                    
                    
                    
Maximum seconds to wait for a single inference HTTP response. Default: 120; 0 = unlimited. Set 0 or higher for long code generation or high thinking levels.

                  


                  

                    
                    
                    
TCP handshake timeout when connecting to PS5LM. Default: 5; valid 1–300. Prevents stalled sockets when PS5LM is restarting.

                  


                  

                    
                    
                    
Retries on transient PS5LM network or 503 errors. Default: 2; 0 = no retries. Increases resilience during model swaps at the cost of retry delay.

                  


                  

                    
                    
                    
Prompt + completion token budget per turn. Default: 8192; 0 = unlimited / PS5LM n_ctx, otherwise 512–1048576. Larger contexts use more PS5 GDDR6 KV-cache RAM.

                  


                  

                    
                    
                    
Maximum tokens generated per model reply. Default: 1024; 0 = unlimited up to context window. Use 0 to prevent truncation when writing full apps or games.

                  


                  

                    
                    
                    
Body limit for chat photo/file attachments, workspace uploads, and extension imports. Default: 67108864 (64 MiB); 0 = 256 MiB max. Large uploads briefly buffer in RAM.

                  


                  

                    
                    
                    
Maximum registered agents allowed at once. Default: 0; 0 = unlimited. Each agent stores minimal SQLite metadata and memory stats.

                  


                  

                    
                    
                    
Maximum concurrent tasks executing across agents. Default: 0; 0 = unlimited. Higher concurrency allows parallel chats and sub-agents using slightly more heap.

                  


                  

                    
                    
                    
Maximum pending root tasks queued before rejecting new requests. Default: 0; 0 = unlimited. Set a finite cap only to enforce backpressure under heavy bursts.

                  


                  

                    
                    
                    
Simultaneous PS5LM inference calls permitted. Default: 4; 0 = unlimited. Match PS5LM total_slots (1–4) to minimize PS5 GDDR6 pressure.

                  


                  

                    
                    
                    
Maximum A2A messages per task tree before loop protection pauses delegation. Default: 0; 0 = unlimited. Finite limits guard against circular agent chatter.

                  


                  

                    
                    
                    
Maximum tool-use turns per task before stopping. Default: 0; 0 = unlimited. Set 0 so multi-step builds finish cleanly without hitting an artificial ceiling.

                  


                  

                    
                    
                    
Wall-clock timeout applied to tasks without an agent override. Default: 0; 0 = unlimited. Useful as a safety fuse for unattended overnight runs.

                  


                  

                    
                    
                    
Allow Commander to spawn temporary specialists for one-off subtasks. Default: true. Temp agents are automatically cleaned up after completion to free RAM.

                  


                  

                    
                    
                    
Action taken on active tasks when an agent is disabled mid-run. Default: cancel. Choose finish_step to avoid partial file writes.

                  


                  

                    
                    
                    
Require manual dashboard approval before mutating tools like delete_file or http_post run. Default: true. Disabling speeds autonomous workflows.

                  


                  

                    
                    
                    
Maximum authenticated HTTP requests per IP per minute. Default: 240; 0 = unlimited. Protects PS5 CPU from accidental client loops; 0 disables throttling.

                  


                  

                    
                    
                    
Hours before dashboard login sessions expire. Default: 24; valid 1–8760. Longer TTLs reduce sign-in prompts on trusted LANs with minimal memory cost.

                  


                  

                    
                    
                    
Maximum long-term memory records retained per agent. Default: 0; 0 = unlimited. Very large counts slightly increase SQLite lookup time and disk usage.

                  


                  

                    
                    
                    
Compact older chat messages into memory summaries after this count. Default: 40; 0 = disabled. Compaction keeps prompt tokens lean and speeds up long chats.

                  


                  

                    
                    
                    
Days before old finished tasks, logs, and audit entries are pruned. Default: 30; 0 = keep forever. Lower values keep PS5 storage footprint small.

                  


                  

                    
                    
                    
Row cap per prunable log/task table during maintenance. Default: 10000; 0 = unlimited. Bounds query latency and disk growth on long-running daemons.

                  


                  

                    
                    
                    
Minimum severity recorded to the runtime ring buffer and rotating log file. Default: info. debug/trace aid diagnostics but increase disk I/O.

                  


                  

                    
                    
                    
Username required for dashboard login. Default: admin. Takes effect on subsequent sign-ins; zero runtime RAM impact.

                  


                  

                    
                    
                    
Require login session and CSRF validation for dashboard APIs. Default: true. Disable only on trusted private LANs.
